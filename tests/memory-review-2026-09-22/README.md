# PVP Agent 记忆审查（2026-09-22）

**结论：已有可复用的记忆基础设施，但尚不足以支持“通过自博弈或人机博弈持续、可验证地提高对战水平”。** 主要问题不在于缺少向量库，而在于经验来源、实际使用归因、人机回流与评测发布尚未形成可信闭环。

- [验证记录](./validation.md)：运行命令、测试结果、复现说明。
- [现有数据快照](./repository-snapshot.json)：本次检查时的记忆库与轨迹数量、玩家类型。

`reproduce_*_findings.py` 为离线诊断脚本，使用临时目录与确定性玩家，不调用真实 LLM，不改已有记忆库。对应 `*-findings-evidence.json` 记录本次输出。脚本旨在证明当前问题，修复后部分诊断值应改变，不能把“继续复现缺陷”当成回归验收目标。
